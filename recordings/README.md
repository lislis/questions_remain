# Recordings

This folder contains the sound files used in the installation.

The folder `testfiles_16khz_8bit` contains short sound snippets for testing naming convention (the padded numbers) and playback, mostly before final texts were done.

The folder `files_22khz_16bit` contains sound files in a higher resolution but named for their content.

The folder `files_final_16khz_8bit` contains the sound files in lower, Arduino appropriate resolution and correct, numbered naming so they can be copied over to the SD-card just like this.

The file `transcript.md` contains the text for the sound files.
